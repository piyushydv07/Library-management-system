# Library Management System

A simple Library Management System built using Python and Streamlit.

## Features

- Dashboard with library statistics
- Add and view books
- Add and view members
- Borrow books
- Return books
- Track available and total copies
- Store data using JSON
- Generate unique IDs for books and members

## Technologies Used

- Python
- Streamlit
- JSON
- pathlib
- datetime

## Concepts Practiced

- Functions
- Dictionaries and lists
- File handling
- JSON data storage
- Exception handling
- Conditional logic
- Loops
- Streamlit UI components

Run the application:

streamlit run app.py
